Embed Our Calculator on Your Site

Add the MyDebtPayoff.com calculator to your website, blog, or financial education platform. The widget is free, responsive, and lets your visitors compare avalanche and snowball strategies instantly.

Embed Code

Copy and paste the following HTML code into your website where you want the calculator to appear:

<iframe src="https://mydebtpayoff.com/embed/" width="100%" height="700" frameborder="0" style="border:none;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.1);" title="My Debt Payoff Calculator"></iframe>

Installation Instructions

  1. Copy the embed code from the code block above.
  2. Open your website editor and navigate to the page where you want the calculator. Switch to the HTML or code view in your CMS or page builder.
  3. Paste the code at the desired location in your HTML. The iframe will automatically fill the width of its container.
  4. Save and publish your page. The calculator will load directly from MyDebtPayoff.com and will always show the latest features and calculations.

Customization Options

You can adjust the following attributes to fit the calculator into your site layout:

Attribute Default Description
width 100% The width of the calculator. Use a percentage for responsive layouts or a fixed pixel value (e.g., "700px").
height 700 The height of the calculator in pixels. Increase this if the calculator content is being cut off at the bottom.
style border:none; ... Inline CSS for visual customization. You can change the border-radius, box-shadow, or add a border color to match your design.
